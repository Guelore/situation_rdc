# Site Situation Sécuritaire RDCongo

## Objectif

Créer un site web qui présente une carte interactive de la situation sécuritaire de la République Démocratique du Congo.

## Public

Le site est destiné, avant tout, à la population congolaise et à toute personne préoccupée par la situation sécuritaire de la RDC.

## Contenu

Le site doit principalement affiché une carte qui montre graphiquement les zones à risque, les zones occupées, les zones safe, etc. qui présenteront des détails sur la zone lorsqu'on clique dessus.
Le site peut aussi présenter quelques informations pertinentes sur la RDC afin de susciter un sentiment patriotique.

## Charte graphique

Le site doit utiliser les couleurs du drapeau de la RDC ; il doit aussi susciter de la compassion et un sens patriotique.

## Contraintes

Le site doit être leger pour permettre aux gens avec une connexion internet de mauvaise qualité d'y accéder.
Le site ne doit récupérer ses informations que via une ou plusieurs sources fiables (principalement des APIs).
Le site doit être joli, très attrayant, tout en restant sobre.
Le site doit être géré avec git pour le versionnage
Lors du développement, des commits réguliers (avec un message descriptif en français) doivent être effectués après chaque modification consistante
Le site doit être développé en HTML, CSS et JavaScript seulement pour permettre un déploiement sur Github Pages
